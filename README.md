# Adaptive Phrasal Verbs

Aplicación PWA hermana de Adaptive English para automatizar los 50 phrasal verbs B2 prioritarios de Adrián.

- 15 preguntas por nivel
- 15 segundos por pregunta
- cuatro respuestas en colores
- contexto, significado, contraste y modo B2 Use of English
- scheduler adaptativo por precisión, velocidad, exposición y confusiones
- progreso local independiente de Adaptive English
- Adrián Visual System 2.0
- acceso directo al Adrián Hub

Publicación: https://adrianxds-ads.github.io/adaptive-phrasal-verbs/
